# Shared Design Rules Index

`docs/design/shared/` defines cross-cutting design contracts applicable across public and admin surfaces.

## Shared Contracts

- [`principles.md`](principles.md) — Product UX principles and visual direction.
- [`interaction.md`](interaction.md) — Control states, keyboard interaction, forms, dialogs.
- [`accessibility.md`](accessibility.md) — WCAG AA compliance, ARIA, focus, contrast, screen readers.
- [`responsive.md`](responsive.md) — Viewport breakpoints, safe areas, layout adaptation.
- [`states.md`](states.md) — Standard data states (loading, empty, error, settled, unavailable).
- [`content-and-copy.md`](content-and-copy.md) — Tone, terminology, CJK formatting, error copy rules.
