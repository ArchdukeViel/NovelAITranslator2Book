# Product UX Principles

UX principles for Dokushodo (読書道).

## Core Principles

### 1. One primary action per decision region
A region — hero, rail, card, form, modal — gets exactly one visually dominant action. Secondary actions stay visible but never out-compete the primary CTA.

### 2. Chrome recedes, content leads
Navigation, controls, and decorations stay quiet and distraction-free. Motifs decorate structure without competing for attention.

### 3. Honest unavailable and incomplete states
Never show a fabricated metric, fake review count, or simulated live ranking. When data is unavailable, render an explicit honest state.

### 4. Privacy-conscious identity
Default to pseudonymous reader identity. Reviews display usernames without public profiles unless explicitly enabled.

### 5. Content leads visual identity
Japanese web novel app aesthetic (bunko-bon shelf, Yokocho Lantern night market) without solemn museum or antiquarian bookshop tropes.
