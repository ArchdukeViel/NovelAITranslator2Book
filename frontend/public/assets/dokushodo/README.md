# Dokushodo Public Assets

Asset directory for Dokushodo (読書道) public brand marks and icons.

## Layout

```text
public/assets/dokushodo/
├── README.md
└── brand/
    ├── apple-touch-icon.png
    ├── brand-logo-bottom-text.svg
    ├── brand-logo-text.svg
    ├── brand-logo.svg
    ├── favicon.ico
    ├── icon-192.png
    ├── icon-512.png
    ├── icon.svg
    └── open-graph.png
```

## Usage

- Brand mark: Lantern logo vector icon (`icon.svg`, `brand-logo.svg`).
- Scalable icons & favicons: `icon.svg`, `favicon.ico`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` under `brand/`.
- Brand wordmarks: `brand-logo-text.svg`, `brand-logo-bottom-text.svg` used in header and footer.
- Open graph: Social preview sharing card (`open-graph.png`).
- Empty / Error / Maintenance states: Pure UI icon components (`Compass`, `AlertTriangle`, `Wrench` via Lucide); PNG illustration files deleted.
