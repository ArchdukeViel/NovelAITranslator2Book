# Dokushodo Public Assets

Asset directory for Dokushodo (読書道) public brand marks and illustrations.

## Layout

```text
public/assets/dokushodo/
├── README.md
├── brand/
│   ├── apple-touch-icon.png
│   ├── brand-mark.png
│   ├── favicon.ico
│   ├── icon-192.png
│   ├── icon-512.png
│   ├── icon.svg
│   └── open-graph.png
└── illustrations/
    ├── 404.png
    ├── empty.png
    └── maintenance.png
```

## Usage

- Brand mark: Lantern logo icon.
- Scalable icon & favicons: `icon.svg`, `favicon.ico`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` under `brand/`.
- Open graph: Social preview sharing card (1200x630).
- 404 illustration: Missing page graphic.
- Empty illustration: Empty state visual component.
- Maintenance illustration: Scheduled downtime shopfront graphic.
